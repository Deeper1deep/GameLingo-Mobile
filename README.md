# GameLingo-Mobile

تطبيق أندرويد بيترجم النصوص الإنجليزية اللي بتظهر جوه فيديوهات الألعاب إلى العامية المصرية في الوقت الفعلي، من غير ما يحمل الفيديو ومن غير ما يبعت صور الشاشة لأي خادم.

## المستودعات

| المستودع | الغرض |
| --- | --- |
| `GameLingo-Mobile` (ده) | سورس الكود، البناء، الاختبارات، GitHub Actions |
| `GameLingo-Updates` | ملفات APK المنشورة، `latest.json`، سجل التغييرات |

## البنية

- Kotlin + Jetpack Compose (Material 3)، واجهة عربية RTL.
- معمارية MVVM: `ui` (شاشات وViewModels) ← `data` (Room + DataStore) ← `core` (أدوات نقية قابلة للاختبار).
- Hilt لحقن الاعتماديات، Coroutines/Flow للتزامن.
- التقاط الشاشة: MediaProjection داخل Foreground Service (`ScreenCaptureService`) مع إشعار دائم وإيقاف نظيف للموارد.
- OCR محلي على الجهاز بـ ML Kit (لا تغادر أي صورة الجهاز أبدًا)، مع كشف تغيّر الإطار لتوفير البطارية، وتتبع استقرار النص، ومنع التكرار، واقتصار على منطقة النص.
- محرك ترجمة هجين خلف واجهة موحدة: Gemini أونلاين بمفتاح المستخدم المجاني (افتراضي)، ومحرك محلي مجاني على الجهاز بـ ML Kit (إنجليزي → عربي) كاحتياطي تلقائي عند أي فشل في الوضع AUTO. الترجمة السحابية متوقفة افتراضيًا ولا تعمل إلا بعد شرح داخل التطبيق وموافقة صريحة من المستخدم؛ حتى ذلك الحين لا يخرج أي نص من الجهاز.
- نسق ترجمة للعامية المصرية (Prompt) جاهز للمزودات القائمة على النماذج اللغوية، مع ذاكرة سياق قصيرة للحوار.
- كل سطر مترجم يُحفظ في سجل Room باسم المحرك الذي أنتجه فعلًا.
- نافذة عائمة فوق اللعبة بتعرض آخر سطر مترجم: قابلة للسحب رأسيًا، وتتبع إعدادات الشفافية وحجم الخط والألوان والموضع، وتتشغل وتتقفل مع جلسة الالتقاط.
- تحديثات من داخل التطبيق: فحص عند فتح التطبيق، عرض التغييرات والحجم، تحميل بتقدّم، تحقق إجباري من SHA-256 واسم الحزمة وشهادة التوقيع، ثم مثبّت النظام الرسمي. أي فشل يحذف الملف فورًا وتفضل النسخة القديمة وبياناتك سليمة.

## الواجهات

ثماني شاشات عربية RTL: الرئيسية (حالة الجلسة + الأذونات المطلوبة + طريقة الاستخدام)، إعدادات الترجمة، إعدادات OCR (معدل الالتقاط، منطقة النص، منع التكرار، تجاهل النص غير المستقر، توفير البطارية)، إعدادات الذكاء الاصطناعي (وضع المحرك، مفتاح API اختياري يُخزن محليًا، المهلة، الـ Cache، سياق الحوار)، إعدادات النافذة العائمة (معاينة حية، الشفافية، حجم الخط، الألوان، المكان)، سجل الترجمات (بحث وحذف ومسح كامل)، حول التطبيق، وقسم ترجمة الصوت المستقبلي. كل إعداد مربوط فعليًا بـ DataStore.

## ثوابت المشروع

- `applicationId` ثابت: `com.gamelingo.mobile` — لا يتغير أبدًا.
- مفتاح توقيع واحد ثابت لكل الإصدارات — لا يُرفع على GitHub أبدًا، ويُحقن من GitHub Secrets:
  - `ANDROID_KEYSTORE_BASE64`
  - `ANDROID_KEYSTORE_PASSWORD`
  - `ANDROID_KEY_ALIAS`
  - `ANDROID_KEY_PASSWORD`
- ممنوع وجود أي API keys جوه السورس أو الـ APK. مزود الترجمة الأونلاين بيستخدم مفتاح المستخدم الخاص من داخل الإعدادات.

## البناء محليًا

المتطلبات: JDK 17 وAndroid SDK (منصة 36).

```bash
./gradlew :app:assembleDebug      # بناء نسخة Debug
./gradlew :app:testDebugUnitTest  # تشغيل اختبارات الوحدة
./gradlew :app:lintDebug          # فحص الأخطاء
```

نسخة Release بتتبنى بدون توقيع محليًا إلا لو ملف `keystore/gamelingo-release.keystore` موجود (متجاهل في git)، والتوقيع الرسمي بيحصل في workflow النشر فقط.

## GitHub Actions

- `CI` (`ci.yml`): بيعمل Build للـ Debug APK، بيشغل اختبارات الوحدة، وlint على كل push وPR على `main`، ويرفع الـ APK والتقارير كـ Artifacts.
- `Publish` (`publish.yml`): يدوي التشغيل، بيرفع versionCode ويحدّث versionName من المدخلات، بيبني Release موقع بالمفتاح الثابت (كلمة سر المفتاح = كلمة سر المخزن في PKCS12)، بيتحقق من التوقيع وشهادة مثبتة بالـ SHA-256 (أي اختلاف يلغي النشر)، وبينشر الـ APK و`latest.json` على `GameLingo-Updates` ويرجّع رفع الإصدار للسورس مع tag. يحتاج سر `UPDATES_REPO_TOKEN` (PAT بدقة محدودة: كتابة المحتوى على GameLingo-Updates فقط) قبل أول نشر فعلي.

## نظام التحديثات

التطبيق عند فتحه بيقرأ `latest.json` من مستودع `GameLingo-Updates`، يقارن الإصدار، يعرض التغييرات والحجم، ينزل الـ APK، يتحقق من SHA-256 واسم الحزمة والتوقيع، وبعدين يفتح مثبت أندرويد الرسمي. لو أي خطوة فشلت، النسخة القديمة بتفضل سليمة وبيانات المستخدم محفوظة.
