# GameLingo-Mobile

تطبيق أندرويد بيترجم النصوص الإنجليزية اللي بتظهر جوه فيديوهات الألعاب إلى العامية المصرية في الوقت الفعلي، من غير ما يحمل الفيديو ومن غير ما يبعت صور الشاشة لأي خادم.

## المستودعات

| المستودع | الغرض |
| --- | --- |
| `GameLingo-Mobile` (ده) | سورس الكود، البناء، الاختبارات، GitHub Actions |
| `GameLingo-Updates` | ملفات APK المنشورة، `latest.json`، سجل التغييرات |

## البنية

- Kotlin + Jetpack Compose (Material 3)، واجهة عربية RTL.
- معمارية MVVM: `ui` (شاشات وViewModels) ← `data` (Room + DataStore) ← `core` (أدوات نقية قابلة للاختبار).
- Hilt لحقن الاعتماديات، Coroutines/Flow للتزامن.
- التقاط الشاشة: MediaProjection داخل Foreground Service (المرحلة الثالثة).
- OCR محلي على الجهاز بـ ML Kit (المرحلة الثالثة).
- محرك ترجمة هجين: أونلاين / محلي / تلقائي مع Cache وContext Memory (المرحلتين الرابعة والخامسة).
- نافذة عائمة قابلة للتحريك والتخصيص (المرحلة السادسة).
- تحديثات من داخل التطبيق بقراءة `latest.json` من مستودع التحديثات (المرحلة الثامنة).

## ثوابت المشروع

- `applicationId` ثابت: `com.gamelingo.mobile` — لا يتغير أبدًا.
- مفتاح توقيع واحد ثابت لكل الإصدارات — لا يُرفع على GitHub أبدًا، ويُحقن من GitHub Secrets:
  - `ANDROID_KEYSTORE_BASE64`
  - `ANDROID_KEYSTORE_PASSWORD`
  - `ANDROID_KEY_ALIAS`
  - `ANDROID_KEY_PASSWORD`
- ممنوع وجود أي API keys جوه السورس أو الـ APK. مزود الترجمة الأونلاين بيستخدم مفتاح المستخدم الخاص من داخل الإعدادات.

## البناء محليًا

المتطلبات: JDK 17 وAndroid SDK (منصة 36).

```bash
./gradlew :app:assembleDebug      # بناء نسخة Debug
./gradlew :app:testDebugUnitTest  # تشغيل اختبارات الوحدة
./gradlew :app:lintDebug          # فحص الأخطاء
```

نسخة Release بتتبنى بدون توقيع محليًا إلا لو ملف `keystore/gamelingo-release.keystore` موجود (متجاهل في git)، والتوقيع الرسمي بيحصل في workflow النشر فقط.

## GitHub Actions

- `CI` (`ci.yml`): بيعمل Build للـ Debug APK، بيشغل اختبارات الوحدة، وlint على كل push وPR على `main`، ويرفع الـ APK والتقارير كـ Artifacts.
- `Publish` (`publish.yml`): يدوي التشغيل، بيبني Release موقع بالمفتاح الثابت، بيتحقق من التوقيع وSHA-256، وبينشر على `GameLingo-Updates` مع تحديث `latest.json`. (يُضاف في المرحلة التاسعة، بعد اكتمال إعداد الـ Secrets.)

## نظام التحديثات

التطبيق عند فتحه بيقرأ `latest.json` من مستودع `GameLingo-Updates`، يقارن الإصدار، يعرض التغييرات والحجم، ينزل الـ APK، يتحقق من SHA-256 واسم الحزمة والتوقيع، وبعدين يفتح مثبت أندرويد الرسمي. لو أي خطوة فشلت، النسخة القديمة بتفضل سليمة وبيانات المستخدم محفوظة.
